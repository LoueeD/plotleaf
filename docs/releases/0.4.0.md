# plotleaf 0.4.0 release candidate

M5 implementation is complete in source; publication is authorized by the owner but awaits manual visual review and final release verification. Public npm remains 0.3.2.

## Scope

- Scoped `explore` directives select complete agent-prepared views. Native dropdown, segmented choice, toggle, literal text/number and supported date-range inputs share deterministic defaults, reset, invalid/unavailable and empty states.
- Every view declares every scoped input. Bound metrics/comparisons, charts, funnel, tables and data alternatives change together. Static content outside the scope stays fixed.
- Existing validation, safe Markdown, file containment, data projection and rich cells are reused. JSON keys/depth/container counts and expansion size/components/rows/data bytes are bounded. Nested explorations, arbitrary queries, analytics and report JavaScript remain unsupported.
- Native controls and visible charts work offline; inactive chart instances are disposed. Default content stays readable without JavaScript. No new dependency, UI framework, persistence, remote fetch or hosting requirement is added.
- The cumulative report retains earlier components. A fictional interactions example, guide/schema and website docs/gallery/playground demonstrate all six controls and coherent region/range transitions.

See [M5 contracts](../m5-interactions.md). The website remains a private package excluded from npm. The explicit package allowlist deliberately adds only three fictional interactions files: Markdown plus two prepared-view JSON bundles (32 approved files total).
