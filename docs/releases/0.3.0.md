# plotleaf 0.3.0 release

Published on 8 November 2026: [plotleaf 0.3.0 on npm](https://www.npmjs.com/package/plotleaf/v/0.3.0). The unscoped package and executable remain `plotleaf`; `latest` resolves to `0.3.0`.

M4 is complete: native table image cells, bounded static sparklines, explicit scalar sort keys, safe local asset loading, deduplicated offline embedding and accessible value disclosures. The cumulative `examples/report.md` retains earlier metrics/comparisons, charts, targets, funnel, prose and tables alongside M4 cells. The owner approved that preview and explicitly requested validation of M4 completion followed by publication. See [M4 contracts and evidence](../m4-rich-tables.md).

## Dependencies and boundaries

`image-size@2.1.0` is a pure JavaScript, zero-dependency MIT package used only by the CLI for bounded PNG/JPEG header dimensions. No browser dependency or per-cell ECharts instance was added. Original raster bytes/metadata, alternatives, sort keys and disclosed values are readable by report recipients. Header/container validation does not decode pixels. Keep those limits explicit rather than claiming full image validation.

Subtotals, filters/prepared-view state, maps and declarative reuse remain later milestones. M5 begins with a concrete prepared-view transition fixture. M4 does not implement those future capabilities.
