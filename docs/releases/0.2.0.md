# plotleaf 0.2.0 release

Published on 8 November 2026: [plotleaf 0.2.0 on npm](https://www.npmjs.com/package/plotleaf/v/0.2.0). The unscoped package and executable remain `plotleaf`; `latest` resolves to `0.2.0`.

M3 adds bounded donut charts, prepared funnel/progress stages, native data disclosures and the fictional onboarding example. Data contracts, source diagnostics, generated component specifications and the report-authoring skill cover both additions. There are no new dependencies. See [M3 contracts and bundle decision](../m3-visualizations.md).
