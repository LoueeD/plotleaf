# plotleaf 0.1.0 release

Published on 7 November 2026: [plotleaf on npm](https://www.npmjs.com/package/plotleaf). The unscoped package and executable are both `plotleaf`; the latest public version is `0.1.0`.

The owner approved publication after manually reviewing the preview and requesting the currency layout/format changes. Revenue displays as `US$824,160` on one line. Whole currency amounts omit `.00`; nonzero cents keep two decimal places. No renderer changes were made after that approval; the release build matched the reviewed asset hashes.
